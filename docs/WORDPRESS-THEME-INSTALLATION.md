## 🚀 **Quick Installation**

### **Method 1: WordPress Admin Upload (Recommended)**

1. **Download the ZIP file**: `dist/dolonia-cybersecurity-theme.zip`
2. **Log into WordPress Admin**
3. **Navigate to**: `Appearance > Themes`
4. **Click**: `Add New` button
5. **Click**: `Upload Theme` button
6. **Choose File**: Select the ZIP file
7. **Click**: `Install Now`
8. **Click**: `Activate` when installation completes

### **Method 2: FTP Upload**

1. **Extract** the ZIP file
2. **Upload** the `wordpress-theme` folder to `/wp-content/themes/`
3. **Rename** the folder to `dolonia-cybersecurity`
4. **Go to** `Appearance > Themes` and activate

## 🛠️ **Troubleshooting**

### **Animations Not Working**
1. Check JavaScript console for errors
2. Verify `dolonia_binary_rain_enabled` setting
3. Try switching to "Low" performance mode
4. Clear browser cache

### **Chat Widget Missing**
1. Check `dolonia_live_chat_enabled` setting
2. Verify container div exists in footer
3. Check for JavaScript conflicts

### **Performance Issues**
1. Lower animation performance mode
2. Reduce active patterns
3. Check server resources
4. Monitor FPS in admin dashboard
