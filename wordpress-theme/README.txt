A modern cybersecurity theme with binary rain effects, glitch animations, and ocean-themed gradients.

== Description ==

Dolonia Cybersecurity is a cutting-edge WordPress theme designed specifically for cybersecurity companies, IT consulting firms, and tech businesses. The theme features:

* **Stunning Visual Effects**: Binary rain background animation and glitch effects on logo
* **Modern Design**: Ocean-themed gradient backgrounds with cyberpunk aesthetics
* **One-Page Layout**: Perfect for showcasing services and converting visitors
* **Responsive Design**: Looks great on all devices
* **SEO Optimized**: Built with best practices for search engine optimization
* **Custom Post Types**: Testimonials and Services management
* **Interactive Features**: Cost calculator, contact forms, newsletter signup
* **Performance Optimized**: Lightweight and fast-loading

== Installation ==

1. Download the theme files
2. Create a new folder named 'dolonia-cybersecurity' in your wp-content/themes/ directory
3. Upload all theme files to this folder
4. Go to Appearance > Themes in your WordPress admin
5. Activate the "Dolonia Cybersecurity" theme

== Setup Instructions ==

After activating the theme:

1. **Upload Your Logo**:
   - Go to Appearance > Customize > Site Identity
   - Upload your logo (recommended size: 200x200px)

2. **Configure Hero Section**:
   - Go to Appearance > Customize > Hero Section
   - Set your hero title and subtitle

3. **Add Contact Information**:
   - Go to Appearance > Customize > Contact Information
   - Add your phone number and email

4. **Create Testimonials**:
   - Go to Testimonials > Add New
   - Add testimonial content, company, position, and rating

5. **Create Services**:
   - Go to Services > Add New
   - Add service descriptions, icons, and pricing

6. **Set Up Navigation**:
   - Go to Appearance > Menus
   - Create a new menu and assign it to "Primary Menu"

== Customization ==

**Colors**: 
Edit the CSS variables in style.css under the ":root" section to change the color scheme.

**Animations**: 
Modify the JavaScript in js/main.js to adjust animation timings and effects.

**Layout**: 
The main content is in index.php. You can modify sections or add new ones as needed.
