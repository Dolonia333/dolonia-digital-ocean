==============================================================================
RATIONALE
==============================================================================

1. FRONTEND: Contains all React/TypeScript UI code
   - Separates presentation layer from business logic
   - Makes it clear where UI changes should go
   - Follows standard React project conventions

2. BACKEND: Contains server-side code
   - Separates API logic from UI
   - Keeps Supabase functions organized
   - Makes server code easier to find and maintain

3. DATABASE: Centralizes all SQL
   - Migrations are version-controlled and organized
   - Schema files are isolated from application code
   - Makes database changes trackable and reviewable

4. CONFIG: Centralizes configuration
   - Environment variables in one place
   - IDE settings separated from code
   - Easier to manage different environments

5. DEPLOY: Deployment-specific files
   - Docker configs separate from source code
   - NAS deployment isolated from main app
   - Easier to manage different deployment targets

6. SCRIPTS: Build and utility scripts
   - Organized by language/type
   - Easier to find and maintain deployment scripts
   - Separates build tools from application code

7. DOCS: Organized documentation
   - Grouped by purpose (guides, debugging, etc.)
   - Easier to find relevant documentation
   - Root-level docs moved to appropriate categories
